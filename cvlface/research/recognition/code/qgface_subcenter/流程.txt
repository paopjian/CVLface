# 备注
################################################################################
# 1. 每阶段的 STAGE*_CKPT 路径需要根据实际运行后的输出目录名称修改
#    (日期和step会变, 格式: prefix_MM-DD_trial/checkpoints_every_epoch/epoch:N_step:M)
#
# 2. pefts.classifier_ckpt_dir: 加载已训练的分类器权重(classifier.pt)
#    models.start_from: 加载backbone权重(model.pt)
#
# 3. 阶段间分类器冻结/解冻逻辑:
#    - models.freeze=True + pefts=freeze: backbone冻结, 只训练classifier
#    - pefts=part_freeze + pefts.target_modules=body.36: 解冻body.36~48,
#      classifier通过ckpt_dir加载但参与训练(grad flows)
#    - pefts=full: 全部参数可训练
#    - 要真正冻结分类器不训练, 需要在optims中将classifier的lr设为0
#      或者使用 classifiers.freeze=True (如果支持)
#
# 4. Parquet缓存: 首次运行会扫描37M文件建立缓存(约10-15分钟),
#    后续启动直接加载约31秒
#
# 5. LD_LIBRARY_PATH 修复: 必须设置, 否则 scipy 会因 libstdc++ 版本不匹配报错
