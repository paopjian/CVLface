## 📁 训练脚本总览 (8个)

### 🌟 使用预训练模型 (推荐!) - 3个脚本

1. train_topofr_from_pretrained.sh          ⭐⭐⭐ 最推荐
   - 使用 TopoFR R100 预训练模型 (Glint360K, 96.57%)
   - 标准 fine-tuning (15 epochs, LR=0.0005)
   - 预期性能: 97%+
   - 时间: ~20h

2. train_topofr_from_pretrained_quick.sh    ⚡ 快速验证
   - TopoFR R100 预训练模型
   - 快速验证 (5 epochs)
   - 时间: ~6h

3. train_topofr_from_pretrained_aggressive.sh  📈 激进策略
   - TopoFR R100 预训练模型
   - 较高学习率 (20 epochs, LR=0.001)
   - 适合数据分布差异大的情况
   - 时间: ~25h

### 🔧 从头训练 - 5个脚本

4. train_topofr_e2e_full.sh                 ⭐ 标准训练
   - 从 AdaFace WebFace12M 预训练开始
   - 完整训练 (20 epochs)
   - 时间: ~25h

5. train_topofr_e2e_quick.sh                ⚡ 快速验证
   - 快速验证版本 (10 epochs)
   - 时间: ~12h

6. train_topofr_e2e_cosine.sh               📈 Cosine调度
   - 使用 Cosine LR (30 epochs)
   - 时间: ~35h

7. train_baseline_adaface_e2e.sh            📊 Baseline对比
   - 纯 AdaFace，无 TopoFR
   - 时间: ~18h

8. train_topofr_0605.sh                     🔧 多阶段训练
   - 4阶段精细训练
   - 时间: ~50h+

## 预训练模型 vs 从头训练

| 特性 | TopoFR预训练 | 从头训练 |
|------|-------------|---------|
| **起始性能** | 96.57% | 随机初始化 |
| **模型架构** | IResNet-100 | IResNet-101 |
| **训练数据** | Glint360K (360K类) | dataset_0605 (791K类) |
| **学习率** | 0.0005 (较低) | 0.001 (标准) |
| **Epochs** | 15 | 20-30 |
| **收敛速度** | 快 | 慢 |
| **最终性能** | 更高 | 较低 |
| **推荐度** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |

## TopoFR vs AdaFace

| 特性 | TopoFR | AdaFace |
|------|--------|---------|
| **损失函数** | 分类+拓扑+GUM | 分类 |
| **训练时间** | +15-20% | baseline |
| **性能提升** | +0.5~1.0% | baseline |
| **内存开销** | O(batch_size²) | O(batch_size) |

## 使用预训练模型时

```bash
# 模型
models=iresnet/configs/v1_ir100.yaml  # ← 注意是 R100
models.start_from=/root/.../Glint360K_R100_TopoFR_9760.pt

# 学习率 (较低)
optims.lr=0.0005  # ← fine-tuning 用较低学习率
optims.num_epoch=15

# 损失 (保持一致)
losses=configs/topofr_adaface.yaml
```

## 从头训练时

```bash
# 模型
models=iresnet/configs/v1_ir101.yaml  # ← R101
models.start_from=/root/.../adaface_ir101_webface12m/model.pt

# 学习率 (标准)
optims.lr=0.001
optims.num_epoch=20

# 损失
losses=configs/topofr_adaface.yaml  # 或其他配置
```
