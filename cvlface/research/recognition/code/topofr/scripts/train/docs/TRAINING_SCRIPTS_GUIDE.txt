## 📊 脚本对比表

| 脚本 | 损失 | Epochs | LR调度 | 数据增强 | 时间 | 用途 |
|------|------|--------|--------|---------|------|------|
| e2e_full | TopoFR+AdaFace | 20 | Step | gridsample | ~25h | 生产 ⭐ |
| e2e_quick | TopoFR+AdaFace | 10 | Step | basic | ~12h | 验证 ⚡ |
| e2e_cosine | TopoFR+AdaFace | 30 | Cosine | gridsample | ~35h | 最佳 📈 |
| baseline | AdaFace | 20 | Step | gridsample | ~18h | 对比 📊 |
| 4-stage | TopoFR+AdaFace | 多阶段 | 各阶段不同 | 各阶段不同 | ~50h+ | 精细 🔧 |

## 💡 使用建议

### 情况1: 第一次使用 TopoFR
```bash
# Step 1: 快速验证
bash train_topofr_e2e_quick.sh

# Step 2: 检查结果
# 如果效果好，继续完整训练

# Step 3: 完整训练
bash train_topofr_e2e_full.sh
```

### 情况2: 对比实验
```bash
# 并行运行 (如果有16卡)
CUDA_VISIBLE_DEVICES=0,1,2,3,4,5,6,7 bash train_baseline_adaface_e2e.sh &
CUDA_VISIBLE_DEVICES=8,9,10,11,12,13,14,15 bash train_topofr_e2e_full.sh &

# 或串行运行 (8卡)
bash train_baseline_adaface_e2e.sh   # 先跑 baseline
bash train_topofr_e2e_full.sh        # 再跑 TopoFR
```

### 情况3: 追求最佳性能
```bash
# 使用 Cosine 调度器 + 更多 epochs
bash train_topofr_e2e_cosine.sh
```

### 情况4: 需要精细控制
```bash
# 使用多阶段训练
bash train_topofr_0605.sh
# 可以在每个阶段后暂停，检查结果再继续
```

## ⚙️ 自定义参数

如果需要修改参数，直接编辑脚本或在命令行覆盖：

```bash
# 示例: 修改 batch size
bash train_topofr_e2e_full.sh
# 编辑脚本中的 trainers.batch_size=256 改为 128

# 或在命令行添加参数
fabric run --devices=8 train_opt.py \
    losses=configs/topofr_adaface.yaml \
    trainers.batch_size=128 \
    # ... 其他参数
```

## ⚠️ 常见问题

### Q1: OOM 错误
```bash
# 解决方案: 减小 batch size
trainers.batch_size=128  # 或 192
```

### Q2: 训练太慢
```bash
# 解决方案1: 使用 quick 版本
bash train_topofr_e2e_quick.sh

# 解决方案2: 临时关闭拓扑损失
# 编辑 losses/configs/topofr_adaface.yaml
topo_weight: 0
```

### Q3: 不确定用哪个
```bash
# 首次使用: quick
# 正式训练: full
# 追求极致: cosine
# 需要对比: baseline
```
