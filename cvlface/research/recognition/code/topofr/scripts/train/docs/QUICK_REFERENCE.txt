┌─ 核心技术 ───────────────────────────────────────────────────────────────────┐
│                                                                              │
│  ✓ 拓扑对齐损失 - 保持输入和特征空间的拓扑一致性                               │
│  ✓ GUM样本加权 - 动态区分清晰样本和困难样本                                   │
│  ✓ 组合损失 - classification_loss + 0.1 × topological_loss                  │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌─ 性能影响 ───────────────────────────────────────────────────────────────────┐
│                                                                              │
│  训练时间:  +15-20%                                                          │
│  内存使用:  +O(batch_size²)                                                  │
│  推荐配置:  batch_size ≤ 512                                                 │
│  预期提升:  IJB-C +0.5-1.0% (TAR@FAR=1e-5)                                   │
