## 💡 关键提示

### 使用预训练模型时注意

1. **模型架构**: 必须使用 IResNet-100 (不是101!)
   ```bash
   models=iresnet/configs/v1_ir100.yaml  # ✓
   models=iresnet/configs/v1_ir101.yaml  # ✗
   ```

2. **学习率**: 使用较低学习率进行 fine-tuning
   ```bash
   optims.lr=0.0005  # fine-tuning
   optims.lr=0.001   # 从头训练
   ```

3. **Epochs**: fine-tuning 需要更少的 epochs
   ```bash
   optims.num_epoch=15  # fine-tuning
   optims.num_epoch=20  # 从头训练
   ```
